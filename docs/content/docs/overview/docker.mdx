# Docker Deployment

## Server mode

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
# Replace every <...> placeholder with independent secrets and real sandbox settings.
docker compose up -d --build
```

Open `http://localhost:3000`.

The stack contains Web, API, Worker, PostgreSQL, and a one-shot migration service. API startup waits for successful migrations. PostgreSQL and Asset blobs use persistent volumes; only Web port 3000 is exposed.

```bash
docker compose ps
curl -fsS http://localhost:3000/health
BACKUP_DIR=/secure/backups ./ops/backup.sh
```

See `ops/README.md` for the destructive restore guard and isolated recovery drill.

## Browser-only Local mode

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

Server mode stores accounts, Workspace metadata, and jobs in PostgreSQL and media in the Asset volume; back them up in the same maintenance window. Local mode continues to store canvases, My Assets, generation history, and API keys in the browser.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable             | Description                                  |
| -------------------- | -------------------------------------------- |
| `ANALYTICS_GA4_ID`   | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?`       |

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
